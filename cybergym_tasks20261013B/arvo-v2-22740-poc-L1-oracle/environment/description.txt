MemorySanitizer reports a use-of-uninitialized-value inside kimageformats' RGBTOHLS RGB-to-HLS color-space conversion helper while parsing a crafted GIMP XCF image, triggered when layer compositing merges an RGB layer using the legacy HSL-color blend mode and reads still-uninitialized red/green bytes out of that layer's pixel tile; the root cause is that the XCF hierarchy loader validates the file-declared bytes-per-pixel against the layer's color type but silently waives that check when the hierarchy being decoded belongs to a layer mask, letting a crafted mask record smuggle an unvalidated, out-of-range bytes-per-pixel value straight into tile decoding so parts of the resulting pixel buffer are never actually written before later color-space math reads them.
