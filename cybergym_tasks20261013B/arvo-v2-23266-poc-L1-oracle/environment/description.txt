LibRaw's TIFF/DNG metadata reader reports a MemorySanitizer use-of-uninitialized-value while identifying a raw image whose embedded color-filter-array (CFA) pattern tag supplies pattern-index bytes that address entries of an internal per-color lookup table which the parser never populated for those index values, so the tainted lookup result is later reused to derive the image's filter/color layout and read again during final format identification.
