ImageMagick (MSan build): a PICT-format image is decoded and then immediately re-encoded back to PICT through the C++ binding layer's read-then-write round trip. While unpacking an already-uncompressed scanline row (bits-per-line under 8), the decoder copies row bytes through a small fixed-size scratch buffer that lives on the unpacking routine's own stack frame and is never zeroed before use; depending on the row's declared bit depth, the unpack step only ever touches part of that scratch space, yet the code that copies out of it afterward is not guaranteed to stay within the portion actually written. Because this particular crafted image decodes as a true-color (non-indexed) tile, the raw scratch bytes are copied straight into a pixel's color channel values and then composited into the destination image, so the indeterminate byte silently rides along through the pixel pipeline. It only trips a use-of-uninitialized-value warning much later, when the image is re-encoded and each channel value is rescaled down to an 8-bit sample for output — at that point the still-uninitialized channel value is read and the sanitizer fires.
