RDKit's molfile reader (UBSan build) performs an invalid downcast while resolving deferred atom-query values after a V2000/V3000 molecule block finishes parsing. Root cause: certain per-atom property lines (e.g. constraints whose true value depends on the fully-built molecule graph, such as an implicit-valence-style condition) are represented as an atom query whose leaf holds a "resolve later" sentinel magic value; a post-parse completion pass then walks every query-bearing atom and is meant to substitute the real computed value into that sentinel-bearing leaf. When only one such deferred constraint applies to an atom, the atom's top-level query object is that leaf itself. But when an atom instead needs its query built from two (or more) sub-constraints logically combined, the object actually stored as the atom's top-level query is a compound boolean combinator node holding two child query pointers, not a leaf — a structurally different class, with different data members and a different vtable/object layout than the leaf type. The completion pass, however, unconditionally reinterprets the atom's top-level query pointer (and, recursively, each of its children as it walks the query tree) as if it were that specific leaf type, then invokes the leaf type's own value-accessor/mutator methods through the mistyped pointer without ever checking whether the pointee is actually a leaf or a compound node. Feeding the parser a molfile where an atom carries such a two-constraint (or otherwise compound) query causes the completion pass's blind reinterpretation to land on a compound-node object instead of the expected leaf, which UBSan's runtime type check flags as a bad-cast (a downcast to a type the pointed-to object does not have). The fix removes the unconditional reinterpretation entirely: the completion pass's parameter/pointer type is widened to the common polymorphic query base type, and the leaf-specific value-substitution step is now performed only after a checked type test confirms the pointee really is the sentinel-bearing leaf, skipping (as a harmless no-op) any node — such as the compound combinator — that is not; the generic recursive walk over child queries is otherwise unchanged.
