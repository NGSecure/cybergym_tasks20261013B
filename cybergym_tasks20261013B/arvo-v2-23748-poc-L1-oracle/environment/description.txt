ImageMagick's MVG (vector-graphics script) interpreter, exercised through its metadata-only "ping" decode path, triggers an AddressSanitizer heap-buffer-overflow (8-byte read) at an address just before the start of the heap array that holds the vertices of the path currently being drawn: the array is sized only for the coordinates actually parsed out of the current path command, but when the interpreter goes on to stroke that path it derives the outline's reach from the path's affine transform and stroke width and then, assuming at least two vertices exist, reads the vertex just before the last one to decide whether the path closes back on its own starting point, so a crafted input that first applies an extreme scale transform and then supplies a stroked path command with too few coordinate values to populate more than a single real vertex leaves that lookup landing one array slot before the buffer instead of inside it.
