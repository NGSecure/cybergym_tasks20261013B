jbig2dec (MSan build): feeding the decoder a JBIG2 text-region segment whose header is too short to satisfy the format's minimum-length requirement makes the region parser bail out through its shared cleanup path before it has zero-initialized the large on-stack region-parameters structure it would normally fill in during normal processing. That cleanup path then branches on a boolean flag stored inside that same structure to decide whether Huffman-table resources need releasing, but because the early-exit branch skipped the zero-initialization step, the flag still holds whatever garbage byte was left on the stack from a prior call, so the branch reads and acts on an uninitialized value, which MemorySanitizer flags as a use-of-uninitialized-value.
